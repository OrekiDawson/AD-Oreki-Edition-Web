# R123：Web 挑战即时完成退役

## 根因

`src/core/oreki-instant-challenges.js` 在挑战启动后的下一帧直接补写完成次数，
并临时抬高 `maxAM` / `maxIP` 后调用原版收益函数。该实现让 C / IC / EC
跳过真实挑战目标，属于 GAMEPLAY LEGALITY 与 PACING 的阻断性问题。

## 修复

- 删除 `src/core/oreki-instant-challenges.js` 及 `src/game.js` 中的调用。
- 自动化仅保留购买前置研究、启动挑战和推进真实资源的职责。
- 完成次数、完成位、奖励和挑战退出只能由原版挑战目标与真实结算产生。
- 同步清理教程、智能执行器说明和阶段节奏检查中的旧“进入即完成”语义。
- `check_game_pace.mjs` 新增 fail-closed 断言：不得重新引入即时完成模块、
  “进入即完成”、“瞬时完成”或“一口气补满”文案。
