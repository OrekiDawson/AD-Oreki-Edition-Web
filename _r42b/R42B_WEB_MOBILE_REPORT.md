## 2. 已修复（4 条）

### 2.1 窄屏目录不跟随当前章（`43eecfb`）

320 档实测：`nav.scrollLeft` 恒 0，当前章按钮在可视带外约 2800px。
`OrekiTutorialModal.js` 新增 `revealActiveNav()`，用 `getBoundingClientRect` 差值定位
（不用 `offsetLeft`，弹窗里块的定位祖先不一定是 nav）；比可视带还宽的长标题
（ch1/ch13）改为对齐左沿，否则居中会切掉章序号。挂载、阶段推进、跳章、附录、翻页都调。
修后逐章点 18 次，当前章按钮左沿可见 **18/18**（ch1/ch13 右沿仍出界，几何上不可能全见）。

### 2.2 目录被分组标题撑到 117px 高（`43eecfb`）

`.c-oreki-tut__nav-label`「附录（不参与主线进度）」在横排里被压到 min-content 逐字换行，
撑出 104px 一列，`align-items: stretch` 再把 25 个按钮全拉到 114px。
修后：目录 47px、按钮 44px、label 17px。按钮同时满足 44px 触屏目标，
弹窗底部「关闭教程」从 32px 抬到 44px。

### 2.3 底栏「上一章 / 回到当前进度 / 下一章」被裁掉、点不到（`bbb0a70`）

**这条必须用命中测试才看得见**：rect 报 48px 高，但 `elementFromPoint` 打在三个按钮中心，
命中的全是 `.c-modal-message`，实际只有顶部十几像素在裁剪框内。
成因：`.c-oreki-tut__layout` 限高，`.c-oreki-tut__main` 是 `min-height: auto` 不肯收缩，
子项合计超出后被 `.c-oreki-tut` 的 `overflow-x: hidden`（连带 `overflow-y: auto`）裁掉。
修法：main/scroll 补 `min-height: 0`，表头/提示/底栏 `flex: 0 0 auto`。
修后：底栏 477→525 完全在容器内，三点采样 3/3 命中自身；正文滚动区 256→220，仍能滚到底。

> 上一轮 AVD 报告里「底栏间隙 0px、三个按钮 48px」的读数没错，但那条判据覆盖不到「点不点得到」。

### 2.4 横屏正文区只剩 17px（`e9f6cbe`）

640×320 实测：正文滚动区 17px，弹窗 327px 比 320px 视口还高 3px。
新增 `(max-height: 520px) and (min-width: 560px)`：目录还原成左侧竖列（15rem）、
隐藏 Esc 提示、layout 64vh。修后弹窗 526×314 落在视口内，正文区 87px，目录竖列可滚。
连带把 `revealActiveNav()` 改成按容器实际溢出方向选轴（竖列用 `scrollTop`），
否则横屏还原成竖列后当前章又滚不进视野。
