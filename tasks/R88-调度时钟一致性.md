# R88：智能执行器调度时钟一致性

## 状态

生产修复已完成，等待提交；未部署 GitHub Pages。

## 根因与修复

`runCycle` 使用 `performance.now()`，而 executor 旧路径把 `Date.now()` 写入共享 `lastBeatAt`，导致后续单调时钟差值长期为负；同时空转调用也提前消耗共享节拍。现已统一使用单调时钟，executor 经过 frame/global/task 三层 gate，且只在 `outcome.acted` 为真时调用 `markExecuted`。
