## 3. Chrome / Edge 的实际网页视口（真实设备）

### 3.1 远程调试通道

手机默认浏览器未设置（`resolve-activity` 返回 `ResolverActivity`）。
Chromium 系在设备上只暴露**一个**抽象 socket 名 `chrome_devtools_remote`：

```
$ adb -s b012e512 shell cat /proc/net/unix | grep -i devtools
@chrome_devtools_remote          # 先被 Chrome 占用
@chrome_devtools_remote_16417    # force-stop Chrome 后，Edge 以 pid 后缀绑定
```

即：**Chrome 在后台运行时，Edge 无法绑定默认 socket**。本轮处理方式为
`am force-stop com.android.chrome` → 重新拉起 Edge → 绑定 `_<pid>` 后缀名 →
`adb forward tcp:9224 localabstract:chrome_devtools_remote_16417`。
（副作用：Chrome 后台标签页被关闭，会话可恢复；未清除浏览数据。）

## 6. 本轮修复与回归

### 6.1 根因（同一类缺陷的四个表现）

1. `index.html` **没有 `meta viewport`** → 移动浏览器按 980 px 虚拟视口排版再缩放：
   真机 DPR 3.5 下 `visualViewport.scale ≈ 0.40`，正文 11 px → **屏幕上只有 4.4 CSS px**，
   点击区高度 30 px → **12 CSS px**。这是全局性问题，与具体组件无关。
2. 修好视口后，桌面布局在 411/392 px 下装不下：
   - 头部 `.l-game-header__center` 是 `position:absolute; right: calc(50% - 25rem); width: 50rem`
     → 必然出界；
   - 维度行是 7 列网格 + `.l-dim-row-multi-button-container { min-width: 25rem }`，
     加上 `.l-dimensions-container { padding: 5px 50px 5px 90px }` →
     文字被挤成竖排、购买按钮只剩一个字符；
   - 侧栏固定 12.8rem（128 px）吃掉近半宽度。
3. 选项页 `.l-options-grid__button { width: 22rem }` + 整行居中 → 两列 47rem，
   在 325 px 内容区里**左右同时被裁**。
4. 离线进度弹窗内层 `min-width: 400px`，在 392 px 视口下超出弹窗边框。

### 6.2 改动（2 个文件，共 +77 行，均为新增，无删除）

| 文件 | 改动 |
| --- | --- |
| `index.html` | +1 行 `<meta name="viewport" content="width=device-width, initial-scale=1">` |
| `public/stylesheets/new-ui-styles.css` | 文末新增 `@media screen and (max-width: 620px)` 块：侧栏 5.6rem、头部改流式堆叠、维度行改「信息一行 / 按钮一行」、选项按钮单列整宽、弹窗 `min-width:0` |

**为什么放 `new-ui-styles.css` 而不是 `oreki.css`**：`--sidebar-width` 由 `new-ui-styles.css`
的 `:root` 定义，且该表在运行时被追加到 `head` 末尾；写在 `oreki.css` 里会被它覆盖，必须 `!important`。

**为什么阈值 620px**：桌面布局的下限约等于 `侧栏 128 + 内容 500 = 628 CSS px`，
低于此值必然裁切；620 留出取整余量。桌面窗口与平板不受影响。

## 8. 复现步骤（供回归）

```bash
export PATH="/c/Users/Oreki/Android/Sdk/platform-tools:$PATH"
D=b012e512

# 1. 本地静态服务（宿主）
python -m http.server 8288 --bind 127.0.0.1 --directory AD-Oreki-Edition

# 2. 让手机访问宿主
adb -s $D reverse tcp:8288 tcp:8288

# 3. 打开页面（Edge）
adb -s $D shell am start -a android.intent.action.VIEW \
  -d "http://127.0.0.1:8288/index.html" -p com.microsoft.emmx

# 4. 远程调试：Chrome 会抢占默认 socket 名，需先停掉
adb -s $D shell am force-stop com.android.chrome
adb -s $D shell am start -n com.microsoft.emmx/com.microsoft.ruby.Main \
  -d "http://127.0.0.1:8288/index.html"
adb -s $D shell "cat /proc/net/unix | grep -i devtools"      # 取 _<pid> 后缀名
adb -s $D forward tcp:9224 localabstract:chrome_devtools_remote_<pid>

# 5. 采集/操作
OREKI_CDP=http://127.0.0.1:9224 node _tools/mobile-live.mjs --nocache metrics
OREKI_CDP=http://127.0.0.1:9224 node _tools/mobile-live.mjs shot _research/shots/real-edge-main.png
OREKI_CDP=http://127.0.0.1:9224 node _tools/mobile-live.mjs file _research/probe-r1-overflow.js
```

**注意**：`adb kill-server` 会清掉所有 `reverse`/`forward` 映射，重连后必须重做第 2、4 步；
否则手机会 `ERR_CONNECTION_REFUSED`，而浏览器里残留的旧页面会让人误判「改动没生效」。
