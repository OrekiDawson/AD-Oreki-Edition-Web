# 仓库目录与中文命名约定

Web 仓库保持**简体中文读者入口 + 稳定英文工具路径**，避免把根目录变成历史报告、临时说明和构建日志的堆放区。

## 根目录用途

| 根目录路径 | 用途与处理原则 |
| --- | --- |
| `README.md`、`AGENTS.md`、`CLAUDE.md`、`LICENSE`、`MOD-LICENSE`、`NOTICE.md` | 项目说明、Agent 规则与许可证，保留约定文件名 |
| `index.html`、`serve.mjs`、`package.json`、`package-lock.json`、`modules/` | 浏览器与 Node 运行基础，不擅自改名 |
| `src/`、`public/` | 游戏业务源码、UI 与静态资源 |
| `scripts/`、`.github/` | 本地验证、生成和 GitHub Actions，CI 引用路径须稳定 |
| `docs/`、`tasks/`、`reports/` | 中文说明、任务与有证据的测试结果，各自单独归档 |
| `archive/` | 过期材料；历史暂停记录已归档到 `archive/项目暂停记录.md` |
| `savestates/` | 脱敏的测试存档及来源/版本清单 |
| `启动游戏.bat` | Windows 用户快速启动入口，保留根目录方便双击 |

`WEB_ANDROID_DIFFERENCES.md` 保留原路径，指向 Workspace 的唯一双端差异台账。

## 中文化与归档约定

- 用户可见内容、文档标题、PR/Issue、发布说明和维护指南使用**简体中文**；源代码标识符、NPM、URL、API、存档字段和框架规定的文件名保留原名。
- `README.md` 是唯一根目录使用说明。新任务写在 `tasks/`，构建测试证据写在 `reports/`，专题解释和技术手册写在 `docs/`；不得再在根目录添加临时暂停、交接和测试快照。
- 不把 `src/`、`public/`、`.github/`、`package.json` 直接译成中文路径；这会让实际引用、CI 或线上部署失效。
- 历史材料移动时保留原文和 Git 历史，并修复当前生效的相对链接；除非重新验证，不改写旧报告的结论。
- **原版存档兼容是硬门禁**：中文化不修改 `AntimatterDimensionsSavefileFormat`、序列化结构、存档槽位、原始购买记录或线上 URL。
- 不直接编辑 GitHub Pages 的生产副本；中文化通过源码 PR、必要的校验和既有部署门禁进行。
