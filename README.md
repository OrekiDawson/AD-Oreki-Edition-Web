# 反物质维度 · Oreki Edition（Web）

《反物质维度》的网页 MOD，保留原版核心机制，并提供简体中文界面、教程、速度设置、智能自动化和移动端布局。

在线地址：<https://oreki.net>

## 1. 适用范围

本仓库是 Web 功能源码和浏览器测试入口。部署副本不作为第二个功能源码入口；Android 端由独立仓库维护，不能用 Web 的运行结果替代 Android 验收。

## 2. 在线使用

使用桌面 Chromium/Firefox/Safari 或 Android Chrome 打开 <https://oreki.net>。存档保存在当前浏览器的站点存储中，不会自动同步到其他设备。

换设备、换浏览器或清理站点数据前，进入“选项 → 游戏玩法 → 存档工具”导出存档并自行保存。

## 3. 本地运行

需要 Node.js。项目直接加载原生 ES 模块，不能用 `file://` 打开入口。

```bash
node serve.mjs 8080
```

然后访问 `http://127.0.0.1:8080/`。

教程正文源为 `src/core/oreki-tutorial-data.json`；修改教程后使用项目已有的结构、术语和生成检查，不直接手改生成物。

## 4. 游戏与界面边界

1. MOD 主动操作和原版自动购买器使用各自的节拍，不能混为一个调度器。
2. 玩家手动操作不受 MOD 全局行动节拍限制；智能策略不强制打开玩家关闭的原版自动购买器。
3. 首次大坍缩后必须真实经历无限阶段，不能立即自动 Break Infinity。
4. 无限阶段隐藏永恒层内容；永恒和现实内容只能在真实结算后显示。
5. 游戏推进不依赖频繁切换页面；页面主要负责显示真实状态，不能通过切页伪造业务触发。

## 5. 测试

根据改动范围运行对应的定向检查。涉及移动布局、阶段显示或自动化刷新时，使用真实移动端视口或 Android Chrome，并保留关键操作前后截图。测试结果区分 `PASS`、`FAIL`、`BLOCKED` 和 `NOT RUN`；静态检查不能替代真实 GUI 验收。

常用目录：

| 路径 | 用途 |
|---|---|
| `src/main.js`、`src/game.js` | 启动入口与主循环 |
| `src/core/` | 游戏机制、存档、自动化和共享状态 |
| `src/components/` | 界面组件 |
| `public/` | 样式和静态资源 |
| `scripts/` | 定向检查和生成工具 |
| `docs/` | 事实、历史验证记录与旧规则归档 |
