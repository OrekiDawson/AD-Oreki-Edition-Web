# 反物质维度 · Oreki Edition（Web）

《反物质维度》的网页 MOD，保留原版核心机制并加入全局速度、智能自动化、简体中文界面和教程。

在线地址：<https://oreki.net>

## 1. 开始使用

### 1.1 在线游玩

使用桌面 Chrome/Edge/Firefox 或 Android Chrome 打开线上地址。网页存档保存在当前浏览器本地，不会自动同步到其他设备。

### 1.2 备份存档

进入“选项 → 游戏玩法 → 存档工具”，使用导出/下载保存文本或文件；换设备、换浏览器或清理站点数据前必须先备份。

### 1.3 速度与自动化

游戏速度、智能调度和原版自动购买器设置位于“选项 → 游戏玩法”。手动操作优先；MOD 主动动作和原版自动购买器购买遵守各自规则，不得混用两个节拍。

## 2. 项目边界

### 2.1 源码仓库

本目录是 Web 源码仓库。功能改动只在这里进行；`web/_deploy/site/` 是部署副本，不是第二个源码源。

### 2.2 Android 对照

Android 端是独立仓库，构建链、存档和验证证据不与 Web 互相替代。共享玩法标准和术语按规则索引引用，不复制另一端的实现。

## 3. 本地运行

### 3.1 环境

需要 Node.js 和项目 lockfile 声明的依赖；Python 只用于少量辅助检查。不要把个人绝对路径、动态版本号或私人环境信息写入 README。

### 3.2 启动开发服务器

```bash
node serve.mjs 8080
```

然后打开 `http://127.0.0.1:8080`。不能直接使用 `file://` 打开 ES Module 入口。

### 3.3 教程数据

`src/core/oreki-tutorial-data.json` 是教程正文的唯一内容源；生成文件由仓库脚本产生，不要手改生成物。修改教程后运行对应的结构、术语和生成检查。

## 4. 测试

### 4.1 定向测试

改哪里验哪里，优先运行与本轮修改直接相关的脚本。测试失败、挂起和未执行必须分开记录。

### 4.2 移动端 GUI

涉及布局、阶段显示或自动化刷新时，必须用真实 Android Chrome 或指定浏览器环境观察屏幕；不能以桌面窗口模拟替代移动端证据。关键操作保留前后截图。

### 4.3 阶段显示

无限阶段隐藏永恒层内容，永恒阶段显示永恒内容，现实内容只能在真实现实结算后显示。资源、入口和预初始化数据不能单独证明阶段已达成。

## 5. 目录结构

| 路径 | 职责 |
|---|---|
| `src/main.js`、`src/game.js` | 启动与主循环 |
| `src/core/` | 游戏机制、存档、自动化和共享数据 |
| `src/components/` | 界面组件 |
| `public/` | 样式、字体和静态资源 |
| `scripts/` | 定向测试与生成工具 |
| `docs/` | 规则、事实、教程说明和报告 |
| `tasks/`、`reports/` | 任务记录与运行证据 |
